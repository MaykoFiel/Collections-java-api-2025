Java Collections Framework - Guia Prático
Este repositório contém uma exploração aprofundada da Java Collections API, desenvolvida como parte da minha formação em Engenharia de Software. O objetivo aqui é documentar o aprendizado sobre as principais estruturas de dados do Java e quando utilizar cada uma delas para garantir a melhor performance da aplicação.

📚 Estruturas Exploradas

List (ArrayList, LinkedList): Implementações focadas em coleções ordenadas que permitem elementos duplicados.
Set (HashSet, LinkedHashSet, TreeSet): Estruturas que não permitem elementos duplicados, ideais para garantir a unicidade dos dados
Map (HashMap, LinkedHashMap, TreeMap): Mapeamento de chave e valor, fundamental para buscas rápidas e organização de dados associativos.
Comparable vs Comparator: Implementação de interfaces para ordenação personalizada de objetos.

💡 O que este projeto resolve?

Em sistemas complexos, como o Molde Gestor que desenvolvi para o setor de pré-moldados, a escolha correta de uma Collection pode ser a diferença entre um sistema rápido ou um sistema travado. Este repositório serve como meu guia de referência para:
Realizar buscas binárias eficientes.
Remover duplicatas de grandes volumes de dados.
Ordenar listas de objetos complexos por critérios múltiplos.

🛠 Tecnologias

Java 17+: Uso de funcionalidades modernas da linguagem.
Paradigma: Programação Funcional e Imperativa aplicada em coleções.
